【ダウンロード】
書籍に掲載したプログラムとラトルズ評価ボード対応MCHPFSUSB frameworkを配布します(すべて無償無保証です)。MCHPFSUSB frameworkはプロファイルをラトルズ評価ボードにあわせて修正してあるほか、プロジェクトのファイル一式を各フォルダに揃えてありフォルダ単位で移動できます。

●応用例

[P168]ピンボールコントローラ─Pinball - R14K50EB.zip
[P176]USB-シリアル変換IC─USB Serial Converter - R18K50EB.zip
[P193]タイニーFATシステム─下記のフラッシュレコーダに含まれます。
[P204]フラッシュレコーダ─Flash Recorder - R2550EB.zip
